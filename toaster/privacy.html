Toaster privacy policy

Last updated: 12 October 2026

Toaster is a private app used only by members of the Albert household. It has no other users.

What it accesses

With each household member's own permission, Toaster reads the calendars that member can see and adds or changes events on them. It only changes or deletes events that it created itself, and only after a person has confirmed them.

Where data is kept

Calendar data and sign-in tokens are stored on a computer in the household's home. They are not stored with any third-party service.

Sharing

Toaster does not sell, share or transfer data to anyone, does not use it for advertising, and does not use it to train AI models. Toaster's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Any user can revoke Toaster's access at any time from their Google account (myaccount.google.com/permissions) or Microsoft account (account.live.com/consent/Manage). Stored data is deleted on request.
